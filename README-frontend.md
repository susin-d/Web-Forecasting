# Weather Forecasting Frontend

This is the frontend component of the Weather Forecasting Application, built with React and Vaadin.

## Prerequisites

- Node.js 16 or higher
- npm or yarn

## Installation

1. Navigate to the project root directory.
2. Run `npm install` to install dependencies.

## Running the Application

1. Run `npm run dev` to start the development server.
2. The frontend will be available at `http://localhost:5173`.

## Features

- User authentication (login/register)
- Current weather display
- Hourly and daily forecasts
- Favorite locations management
- Weather alerts

## Building for Production

Run `npm run build` to build the application for production.

## Configuration

The frontend communicates with the backend at `http://localhost:8081` by default. Update the API base URL in the services if needed.

## Technologies Used

- React
- Vaadin Flow
- TypeScript
- Vite
